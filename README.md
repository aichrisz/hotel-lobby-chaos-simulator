# Front Office RPG Simulator

A mobile-first gaming-themed German hotel reception practice app for Abel.

**Hotel Quest: Front Office RPG** — pick a quest, play through a German guest dialogue (multiple-choice + typing), earn score, rank, and XP. Built with Vite + React + TypeScript + Tailwind CSS v4 + Vitest.

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

| Script | What it does |
|---|---|
| `npm run dev` | Start Vite dev server |
| `npm test` | Run Vitest test suite once |
| `npm run test:watch` | Run Vitest in watch mode |
| `npm run lint` | Run ESLint |
| `npm run build` | Type-check (`tsc -b`) and build production bundle |
| `npm run preview` | Serve the production build locally |
